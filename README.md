# codex启动动画（鲸鱼版）

Codex 启动动画的网页复刻版，整段动画打包成一个 HTML 文件，双击即可播放，不联网也能跑。

## 打开方式

- 在线播放：`https://<用户名>.github.io/codex-startup-animation/`
- 离线播放：下载本仓库，用浏览器打开 `index.html`
- 手机播放：用手机浏览器打开上面的在线地址，或扫描 `qr.png`

## 说明

- 单文件实现，所有画面、字体回退和样式都内嵌在 `index.html` 里，没有外部依赖
- 桌面端保持原始构图与节奏；手机竖屏单独排版，手机横屏与桌面端一致
- 已适配移动端安全区（`viewport-fit=cover`），横竖屏切换不会错版

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 动画本体，可直接播放 |
| `qr.png` | 扫码分享用二维码 |

动画内容为学习交流用的视觉复刻。
